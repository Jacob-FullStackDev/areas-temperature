# **Areas Temperature**

## Features

- The client is able to get the current tempature in any country/state/city.
- The client is warned when the provided state/city doesn't exist
- The client can toggle the displayed weather to be in **°F** or **°C**.
- A location can be saved to get the tempature when clicking the **Save location** button, and is stored in LocalStorage.
- A location can also be removed via clicking the remove button when the saved location is generated, and will also be removed from LocalStorage.
- Duplicate locations are unable to be added.

## Technologies used

- **HTML**
- **CSS**
- **JavaScript**
- **Git Bash (project management)**
- **VSCode (Codebase management)**
- **Openweathermap API (weather data)**
- **Openweathermap Geocoding API (to ensure a city matching the provided name is present within a state)**
